### Hyperodds

The console for Hyperliquid outcome markets: markets from every HIP-4 deployer in one place, with
fair lines, the settlement rules compared and the full cost of an order before you sign it.

- Console: [usehyperodds.com](https://usehyperodds.com)
- Open source: [github.com/usehyperodds](https://github.com/usehyperodds)
- MCP for agents: `npx -y @hyperodds/mcp`
- X: [@UseHyperodds](https://x.com/UseHyperodds)
